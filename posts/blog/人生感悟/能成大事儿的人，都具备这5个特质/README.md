# 能成大事的人，都具备这5个特质







1.拥有强烈的好奇心，这决定了你会不断拓展自己认知的边界。（动力）

2.敢于拥抱不确定性，这能让你有机会碰到大机会，获得更大的成功。（勇敢）

3.有更大的目标和想象力，这决定了你在面对短期收益的时候，不会固步自封。（超越）

4.延迟满足和极度自律，这决定了你在日复一日的枯燥中，有耐心走完全程，不至于中途放弃。（坚持）

5.不怕犯错和善于自省，这能让你不断升级迭代，你的成长会比别人更快。（成长）
